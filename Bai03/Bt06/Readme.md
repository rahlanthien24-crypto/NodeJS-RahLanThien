## 2. Mục tiêu bài tập
Xây dựng module tính điểm trung bình của 3 môn
và xếp loại học tập bằng Node.js.

## 3. Các file chương trình
- bai06.js: Chứa dữ liệu 3 sinh viên, sử dụng require()
  để gọi các hàm và hiển thị kết quả.
- xulyDiem.js: Chứa hàm tính điểm trung bình,
  xếp loại học tập và module.exports.

## 4. Xếp loại học tập

- Khá: Từ 6.5 đến dưới 8.
- Trung bình: Từ 5 đến dưới 6.5.
- Yếu: Dưới 5.
